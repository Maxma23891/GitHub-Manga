## Ep 5 การเเก้เเค้นเเละครอบครองโลก

ในช่วงเวลาที่ชีวิต ต้องเลือกเส้นทาง จิ้งจอก รวมพลัง จนสามารถสร้างทุกสิ่ง ออกเดินทางไปรวบรวม เหล่าพันธมิตรที่เคยมีในอดีต อย่าง The wolf นักวิทยาศาสตร์สติเฟื่อง เลื่่องชื่อ ขอให้ช่วยรวบรวมขบวนการเเละสร้างฐานปฏิบัติการ จึงได้เจอกับ จิ้งจอกเหลือง หมาป่า เเกะ เเละ วัว จนกลายเป็นขบวนการ 5สี มีเป้าหมายคือทำลาย เหล่าพวกเก้งชั่ว ที่หลอกให้จิ้งจอก ต้องฆ่าบอส นายผู้ที่รักที่สุด เเละการครองโลก 
เขาจึงบุกเข้าไป ที่เหล่าพวกเเก้งชั่วที่มีอิทธิพล เเละทำลายจนหมดสิ้น เเละ ได้เจอบอสชั่ว 
"[บังอาขมาทำลายฐานของข้า ไอ้เจ้าจิ้งจิก เจ้ามันก็เเค่เด็กในมือ]" 
ทั้งสองจึงได้สู้กัน เเละ จิ้งจอกก็ชนะด้วยพลัง ที่ก่อเกิด จากความเเค้น 
เเล้วเขาก็ประกาศชัยชนะ เเละ เก็บค่าบริการจาก ชาวโลก ทุกคนเต็มใจที่จะจ่ายเพราะ เห็นการปราบเเก้งชั่วได้ 
เเล้วเขาจัดฉาก เเก๊งชั่วโดยให้ หมาป่าสีเทา สร้างเหล่า สมุนปีศาจ เพื่อจัดฉากโลกนี้ เเละกอบโกยเงิน ไปอย่างมั่งคั่ง

## Ep 6 การซ้ำรอย ของเวลา
หลังจากที่เขาถึงจุดสูงสุด เขาใช้พลังของเขาเเปลงร่างเป็นมนุษย์ เเละ ไปหา จิ้งจอกตัวนึง ที่มีข่าวลือว่าเป็นคนที่ไม่มีใครเห็นค่า เเล้วรับมาอยู่ด้วย เเละเรื่องราว ก็วนลูปอีกนับได้ไม่จำกัด เป็นเรื่องราวเเบบ Paradox ที่ไม่รู้จบ เผชิญความสิ้นหวังต่อไปจบบริบูรณ์ ขอบคุณที่ฟังเรื่องเเปลกๆ
